# CloudSSH 客户端安装包

CloudSSH 客户端的安装包发布页，源码不在这里。下载见右侧 [Releases](../../releases)。

- **Windows**：`CloudSSH-Setup-<版本>-x64.exe` 是安装版，会自动更新；`CloudSSH-<版本>-win-x64.zip` 是免安装版，不自动更新
- **Android**：`CloudSSH-<版本>-release.apk`
- **iOS**：`CloudSSH-<版本>-unsigned.ipa` 没有签名，用 Sideloadly 或 AltStore 拿自己的 Apple ID 签名后安装（免费 Apple ID 签的，7 天后要重签一次）

电脑客户端的自动更新从这里的 Releases 下载（`latest.yml`）。
